வழிகாட்டல் பக்கம்

வெளியிடப்படும் சரியான PDF-களை மாணவர்களிடம் கொண்டு சேர்ப்பது எப்படி?

இந்தப் பக்கம் Google Drive அல்லது PDF catalogue-ஐ நேரடியாக மாற்றாது. மாணவர்களுக்கு வெளியிடப்பட்ட PDF-கள் மட்டுமே student-facing library-யில் தோன்றும். தயாரித்தல், metadata சரிபார்த்தல் மற்றும் வெளியிடுதல் போன்ற நிர்வாகப் பணிகள் பாதுகாக்கப்பட்ட வெளிப்புற நிர்வாகச் செயல்முறையில் நடைபெற வேண்டும்.

⌑

பாதுகாப்பான எல்லை

இந்தப் பக்கம் படிக்க மட்டுமே. இங்கு login, password, file upload, Google Drive credentials, metadata editing அல்லது publishing action எதுவும் செயல்படுத்தப்படாது.

முதல் படி

இது எப்படி வேலை செய்கிறது?

வெளிப்புற நிர்வாகி PDF-ஐத் தயாரித்து, தேவையான தகவல்களைச் சரிபார்த்து, வெளியிடப்பட்ட catalogue-ல் சேர்க்கிறார்.

வெளிப்புற நிர்வாகச் செயல்முறை

PDF மற்றும் அதன் பதிவுத் தகவல்கள் பாதுகாக்கப்பட்ட நிர்வாக சூழலில் தயாரிக்கப்படுகின்றன. இந்த தகவல் பக்கம் அந்தச் செயல்முறையை மட்டும் விளக்குகிறது; catalogue-ஐ மாற்றுவதில்லை.

தயாரிப்பு
தேவையான PDF-ஐ நிர்வாகி தயார் செய்கிறார்
சரிபார்ப்பு
PDF மற்றும் metadata முழுமையாக உள்ளதா எனப் பார்க்கப்படுகிறது
வெளியீடு
Published catalogue-ல் மட்டும் பதிவு சேர்க்கப்படுகிறது

மாணவர் library-யின் அடிப்படை விதி

மாணவர்கள் பயன்படுத்த வேண்டிய பொருட்கள் Published நிலையில் இருக்கும் பதிவுகள் மட்டுமே. Draft, Unpublished அல்லது முழுமையற்ற பதிவுகள் student-facing library-யில் காட்டப்படக்கூடாது.

படி 2

நிர்வாக செயல்முறை

ஒவ்வொரு PDF-க்கும் தெளிவான அடையாளமும் சரியான student-facing இணைப்புகளும் இருப்பதை உறுதி செய்வதே இந்தச் செயல்முறையின் நோக்கம்.

சரிபார்ப்பு வரிசை

தயாரிப்பிலிருந்து வெளியீடு வரை

கீழே உள்ள படிகள் நிர்வாகி பின்பற்ற வேண்டிய வழிகாட்டல். இந்த browser பக்கம் எந்த server-side file operation-ஐயும் செய்யாது.

  1. PDF-ஐத் தேர்வு செய்து தயார் செய்யவும் தேவையான ஆவணம் சரியான பதிப்பு மற்றும் வாசிக்கக்கூடிய நிலையில் உள்ளதா என administrator உறுதி செய்ய வேண்டும்.
  2. Metadata-வைச் சரிபார்க்கவும் Title, subject, category மற்றும் language ஆகியவை சரியாகவும் முழுமையாகவும் உள்ளதா எனப் பார்க்க வேண்டும்.
  3. Published status-ஐ உறுதி செய்யவும் பதிவு Published நிலையில் இருப்பதை administrator உறுதி செய்த பிறகே அது மாணவர்களுக்குக் கிடைக்க வேண்டும்.
  4. மாணவர் library-யில் சரிபார்க்கவும் பதிவு PDF Library-யில் தோன்றுகிறதா, மேலும் அதன் preview சரியாக உள்ளதா எனப் பார்க்க வேண்டும்.

படி 3

மாணவர்களுக்கு என்ன நடக்கும்?

வெளியிடப்பட்ட மற்றும் முழுமையான பதிவுகள் மட்டுமே மாணவர் அனுபவத்தில் தெரியும்.

Published

Preview மற்றும் download

கிடைக்கும் பதிவுகளை மாணவர்கள் preview செய்து, வழங்கப்பட்ட download URL மூலம் பயன்படுத்தலாம்.

Unpublished அல்லது முழுமையற்ற பதிவுகள் மாணவர்-facing catalogue-ல் காட்டப்படாது.

படி 4

பாதுகாப்பு எல்லை

நிர்வாக மாற்றங்கள் மாணவர்-facing பக்கத்தில் செய்யப்படக்கூடாது.

பாதுகாக்க வேண்டியது எங்கு நடக்க வேண்டும் இந்தப் பக்கத்தின் நிலை
Login மற்றும் password பாதுகாக்கப்பட்ட backend இங்கு login form அல்லது password field இல்லை
Google Drive credentials வெளிப்புற administrator workflow Credentials இங்கு சேமிக்கப்படவோ காட்டப்படவோ இல்லை
File upload பாதுகாக்கப்பட்ட file service Upload control இங்கு இல்லை
Publishing action Authenticated administrator workflow Publish அல்லது save button இங்கு இல்லை
Metadata editing Role-protected backend Editable metadata form இங்கு இல்லை

படி 5

சிக்கல் தீர்வு

PDF தெரியவில்லை என்றால் administrator முதலில் published status-ஐச் சரிபார்க்க வேண்டும். அடுத்து subject, language, preview URL, download URL மற்றும் title உள்ளிட்ட metadata அனைத்தும் சரியாக உள்ளதா எனப் பார்க்க வேண்டும். பதிவில் ஏதேனும் தகவல் முழுமையற்றதாக இருந்தால், பாதுகாக்கப்பட்ட வெளிப்புற நிர்வாகச் செயல்முறையில் அதைச் சரிசெய்து பின்னர் library-யை மீண்டும் சரிபார்க்க வேண்டும்.
